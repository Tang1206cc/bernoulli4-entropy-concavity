ABSTRACT
--------
Let B_1,...,B_4 be independent Bernoulli random variables with a common
parameter p, and let w_1,...,w_4 be arbitrary strictly positive real weights.
We give a computer-assisted finite classification, followed by an analytic
proof, that the Shannon entropy of sum_i w_i B_i is strictly concave in p.
With natural logarithms, the sharp bound is H_w''(p) <= -16 + 6 log(6)
for 0 < p < 1, with equality exactly when all weights are equal and
p = 1/2. The classification reduces all positive real
weights to 23 subset-sum collision types. Its complete finite certificate
uses only rational arithmetic. Five elementary entropy-loss functions
suffice for the analytic part. A separate rational interval certificate
checks strict curvature on all 23 types without using those analytic
estimates.
